The World in One Day — Thursday 26 November 2026: the whole world's news in one illustrated image. 21 stories across 6 regions, the date itself as the masthead: Trump's tariff wave hits 14 partners, Houthis claim a Saudi refinery hit as Brent tops $94, Shenzhou-24 carries the first foreign astronaut — plus a timeline, a numbered world map, the day in numbers, and a DATE CHECK naming yesterday's stories left out on purpose.

## Run it

```sh
node main.ts
```

This copies the pre-rendered `entry.png` (1024×1024) to the output directory. The image itself was drawn by `render.py` (Python 3 + Pillow, no network, no external assets) and is committed in this repository; `main.ts` stays Node stdlib only so it runs in the grader's Node-only image.
